# MIT 许可证 + 零遥测

Dotlink 以 MIT 发布，运行时不采集、不上报任何数据。

## 为什么

许可证和遥测是这类自托管工具的两个信任信号，也是我们相对竞品最便宜的差异化：

- 竞品里 NetBird 与 Pangolin 是 AGPLv3，ZeroTier 在 1.16.0（2025-08-21）把 controller 移出默认构建转 source-available，Netmaker 的核心在付费墙后面。MIT 让「公司内部部署」「二次分发」「嵌进自己的产品」都不需要法务介入。
- 零遥测意味着 Control Plane 不需要一个「上报端点」，也就没有一条能把自部署实例串起来的暗线。对一个「每人自己部署、没有账号」的产品，这是可验证的承诺：抓包就能证明。

## 代价

- 放弃 AGPL 的双重许可收入路径，也放弃「核心开源、托管收费」的商业模型。
- 没有崩溃数据。排障依赖用户手动贴日志，要有很好的 `dotlink doctor` 与结构化日志来补偿。
